02Add / import holdings

Fill this in and click Add — it lands in the ledger below immediately. The form clears so you can keep entering the next one. Invested and current value are calculated automatically from shares × price.

Two formats work here. A flat table — one row per lot with a Symbol column, plus whichever of Portfolio, Broker, Recommended by, Trade date, Shares, Invested price, Dividend, Current price you have (unlabeled rows land in the first portfolio). Legacy Expenses values are still accepted during import and are moved to the matching recommendation commission total. Or a per-stock trade history — the stock symbol on its own line, followed by a Date / Type / Quantity / Price table, repeated for as many stocks as you like in one paste; only "buy" rows become holdings (log "sell" rows in the Transactions section instead).

04Fallback data connection

Google Sheets stays here as a fallback. You do not need to change your existing sheet just to use Angel One. Leave this connected if you want a second price source or a backup when SmartAPI history is temporarily unavailable.

One-time setup
In your sheet, keep a Symbol column and a Price column, e.g.
=IFERROR(GOOGLEFINANCE(IF(ISBLANK(C2),B2,C2&":"&B2),"price"),"-")
Then paste either link below: the normal address-bar link with Share → "Anyone with the link" → Viewer turned on, or a File → Share → Publish to web → CSV link.

05Price history & alerts

Angel One history is used first when connected. Your existing Date / Close rows in Google Sheets are still supported as a fallback; no second sheet is required.

Sheet layout expected
Your existing layout is supported: each stock row contains the Symbol in column B, and the following two rows contain Date / Close history starting from column H. Example: Date → 09/07, 09/08, 09/09... and the next row Close → 862.65, 867, 829.65....
History is checked automatically when you refresh the portfolio.

06Transactions & realized profit

Log a buy or sell by hand. A Buy is automatically added to Holdings, while a Sell reduces the matching holding lots FIFO and is included in realized profit. You can still edit the holdings ledger directly below.

You can use your own short symbol in Instrument. For a stock whose Angel One symbol differs, add an exchange/token mapping in Settings → Angel One SmartAPI. For example, JYOTI can map to BSE token 504076 while the portfolio continues to display JYOTI.

How WealthLedger works

Local-first
1
Enter your transactions

Add a Buy in Transactions. WealthLedger synchronizes it into Holdings and rebuilds FIFO automatically. Sells reduce holdings and feed the realized report.

2
Refresh market data

Use Refresh prices & calculate to fetch current prices from Angel One. When Angel One is unavailable, Google Sheets remains the fallback.

3
Back up your data

Download a JSON backup before changing browsers or devices. Restore that file on the other copy.

Angel One connection

The public page never stores your Angel credentials. The Cloudflare Worker holds the secrets and exposes only the read-only market-data bridge.

⚙
Common troubleshooting
Angel One says connection error: test /api/health on your Worker first. If it reports an active session, use the production site rather than opening the HTML as a file:// URL.
Prices are blank: check the Worker URL in Settings, then run Refresh prices & calculate.
A newly added Buy is missing: check Transactions for the saved Buy, then return to Portfolio; the holding is rebuilt from the transaction history.
Absolute return and each stock's Profit use the gross stock cost (shares × invested price) and current value. Recommendation commissions are kept separate and are included only in XIRR when a Recommended by filter/report is applied. XIRR treats each row's trade date and invested amount as a dated cash outflow, plus current value on the valuation date as the final inflow — rows without a trade date are excluded from XIRR but still count toward absolute return. Market data can be refreshed through the secure Angel One Worker bridge; Google Sheets remains supported as a browser-friendly fallback and needs the sheet link-shared as viewable. Reports uses the same local Holdings and Transactions data for realized P&L, XIRR, allocation and recommendation analysis. Help explains the main workflows and troubleshooting steps.
