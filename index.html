02Add / import holdings

Fill this in and click Add — it lands in the ledger below immediately. The form clears so you can keep entering the next one. Invested and current value are calculated automatically from shares × price.

Two formats work here. A flat table — one row per lot with a Symbol column, plus whichever of Portfolio, Broker, Recommended by, Trade date, Shares, Invested price, Expenses, Dividend, Current price you have (unlabeled rows land in the first portfolio). Or a per-stock trade history — the stock symbol on its own line, followed by a Date / Type / Quantity / Price table, repeated for as many stocks as you like in one paste; only "buy" rows become holdings (log "sell" rows in the Transactions section instead).

03Holdings

Everything you've added lands here — this is the only place values can be edited. Click any cell to change it; Invested, Current value, Price change, % change and Profit recalculate automatically. To sell, check the box on the lot(s) you're selling — one lot or several of the same stock — then click Sell selected below.

03Angel One SmartAPI

PRIMARY MARKET DATA

Angel One current prices & history

WealthLedger can use a small secure Worker as the bridge to Angel One. Your Angel credentials stay in the Worker — never in this public page. Google Sheets remains available as a fallback.

Not connected
One-time Worker setup
Deploy the angel-worker folder from this package to Cloudflare Workers, add the four Angel secrets there, then paste the Worker URL above. The page only calls read-only market-data endpoints. No Angel login, PIN, TOTP, API key, or order API is exposed here.

04Fallback data connection

Google Sheets stays here as a fallback. You do not need to change your existing sheet just to use Angel One. Leave this connected if you want a second price source or a backup when SmartAPI history is temporarily unavailable.

One-time setup
In your sheet, keep a Symbol column and a Price column, e.g.
=IFERROR(GOOGLEFINANCE(IF(ISBLANK(C2),B2,C2&":"&B2),"price"),"-")
Then paste either link below: the normal address-bar link with Share → "Anyone with the link" → Viewer turned on, or a File → Share → Publish to web → CSV link.

05Price history & alerts

Angel One history is used first when connected. Your existing Date / Close rows in Google Sheets are still supported as a fallback; no second sheet is required.

Sheet layout expected
Your existing layout is supported: each stock row contains the Symbol in column B, and the following two rows contain Date / Close history starting from column H. Example: Date → 09/07, 09/08, 09/09... and the next row Close → 862.65, 867, 829.65....
History is checked automatically when you refresh the portfolio.

XIRR by stock, by recommendation

Every stock recommended by each person, grouped together — current holdings and booked (realized) profit/loss both included, plus a blended total per recommender. A stock shows here even after it's fully sold, tagged "sold out", so the booked result isn't lost.

Absolute return uses invested and current value exactly as entered. XIRR treats each row's trade date and invested amount as a dated cash outflow, plus current value on the valuation date as the final inflow — rows without a trade date are excluded from XIRR but still count toward absolute return. Market data can be refreshed through the secure Angel One Worker bridge; Google Sheets remains supported as a browser-friendly fallback and needs the sheet link-shared as viewable. The realized profit report tracks whatever buy/sell entries you log manually, matched FIFO per instrument, independent of the holdings table.
