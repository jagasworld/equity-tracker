Storage & Google Drive sync

Local mode remains the default. Google Drive mode stores a private Ledger JSON file in the signed-in user's Drive so the same data can be used on multiple devices. Your data is not sent anywhere until you connect Google Drive.

Setup required once by the site owner: create an OAuth Client ID in Google Cloud Console, enable the Google Drive API, add your GitHub Pages origin as an authorized JavaScript origin, and paste the Client ID here. The Client ID is public; never paste a client secret.

Local browser storage is active.

Choose how to start on this device

A Ledger file already exists in Drive, but this browser has no sync baseline. Your local data will not be discarded unless you choose to use the Drive copy.

Sync behavior: independent changes are merged. If the same record was changed on two devices, Ledger asks which version to keep. Offline edits stay local until you sync. For best results, sync before and after switching devices.

Expense grid import — copy/paste or CSV

You can copy an expense sheet like Excel/Google Sheets and paste it below. First column = category, first row = day/date headers. Day headers can be 1, 2… or values such as 1.5, 2.5; the integer day is used. Leave cells blank when there is no expense. Formula cells such as =200+300+600 are supported.

Spreadsheet row import

For normal rows, paste tab-separated columns: Date, Type, Category, Amount, Account, Payment Method, Merchant, Note.
